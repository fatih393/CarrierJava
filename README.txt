Bu proje, challenge projesinin Java ile yeniden geliştirilmiş halidir. Amaç, daha önce edinilen backend geliştirme deneyimini farklı bir dil üzerinde uygulamak ve Java tarafında pratik kazanmaktır.

Proje kapsamında herhangi bir ek teknoloji veya framework kullanılmadan, temel yazılım geliştirme prensiplerine odaklanılmıştır. Yapı olarak Onion Architecture ve CQRS yaklaşımı benimsenmiştir. Bu sayede katmanlı yapı, sorumlulukların ayrılması ve daha sürdürülebilir bir sistem tasarımı üzerine çalışılmıştır.

Bu proje, Java ekosistemine adapte olmak ve mimari yaklaşımları farklı bir dil üzerinde uygulayarak geliştirme becerilerini artırmak amacıyla oluşturulmuştur.
